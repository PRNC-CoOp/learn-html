HTML Basics & Boilerplate

1. <!DOCTYPE html> — This tells the browser that we are using HTML5, which is the modern version of HTML. It does not create anything on the webpage. It simply tells the browser how to read the HTML.


2. <html lang="en"> — This starts the main HTML document. Think of <html> as the big container that holds the entire webpage. <code>lang="en"</code> tells the browser that the main language of the webpage is English.


3. <head> — This starts the head section. The head contains information and settings about the webpage that are mainly used by the browser. Things like the page title, character settings, and mobile settings go here.


4. <meta charset="UTF-8"> — This tells the browser how to understand and display characters. UTF-8 allows the webpage to correctly show letters, different languages, symbols, emojis, and things like the ₹ symbol.


5. <meta name="viewport" content="width=device-width, initial-scale=1.0"> — This tells the browser how the webpage should fit on the user's screen. width=device-width means the webpage should use the device's screen width. initial-scale=1.0 means the webpage should start at normal zoom. This is important for making websites work properly on phones.


6. <title>Document</title> — This sets the name of the webpage. The word "Document" will usually appear in the browser tab. You can change it to something like "My Portfolio" or "My Website".


7. </head> — This tells the browser that the head section is finished. After this, we move to the main part of the webpage.


8. <body> — This starts the body section. This is where you put the actual content that users see and interact with, such as headings, paragraphs, images, buttons, links, and forms.


9. </body> — This tells the browser that the body section is finished. Everything that belongs to the visible webpage content should normally be placed between <body> and </body>.


10. </html> — This tells the browser that the entire HTML document is finished. In simple words, <html> holds the whole webpage, <head> contains information and settings about the webpage, and <body> contains the actual content users see.
